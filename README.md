# 💻 IT på 5 minutter

Interaktiv nettside laget for en utdanningsmesse for 10.-klassinger.

## Inneholder
- IT-quiz
- Cyber Challenge
- IT-support-utfordring
- Interaktiv nettsidebygger
- Kort informasjon om ulike IT-områder
- Mobiltilpasset design

## Publisere på GitHub Pages

1. Lag et nytt repository på GitHub.
2. Last opp:
   - `index.html`
   - `style.css`
   - `script.js`
3. Gå til **Settings → Pages**.
4. Under **Build and deployment**, velg:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Trykk **Save**.
6. Vent litt, og åpne GitHub Pages-lenken som GitHub viser.

Nettsiden bruker ingen database eller server, så den kan kjøres direkte fra GitHub Pages.
